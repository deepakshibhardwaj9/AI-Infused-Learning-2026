# LLM : LARGE LANGUAGE MODEL
- For example : Open ChatGPT, enter a query, explain me LLM. When ChatGPT will give us answer, token by token and explain the answer. So, ChatGPT is doing prediction of the next word/token.
- LLM is doing the predictions, what would be the next token for this sentence.
- For example, when we write a word on WhatsApp, we have given the recommendations for three words that what would be the next word. So, these predictions are done by LLMs using tokenization.

# TOKENS
- Tokens are the words/chunks of a word, every LLM model has there own format for token.
- For example : In a sentence "Hello from Shivak Aggarwal", the LLM model tell that there are 6-tokens and 26-characters in this sentence. "Hello" is one token, "from" is second token, "Shiv" 3rd token, "ank" 4th token, "Agga" 5th token, "wal" 6th token.
- So, token is not a single word, it can be combination of words. This process is known as tokenization.
- LLMs will give us free services up to a certain limit of tokens, and after that LLM will charge some amount for per token.
- There are so many companies (Microsoft, MEta, Uber, etc.), which discard LLM services, as LLMs increase the price for token or reduce the token size. If earlier the token size is 3/4th of the word, they reduce the size to 3-4 characters per word.
- Why LLM exists only in English language? Although LLM understand other languges, but, if we write same word in any other language than English, the token size increases, and this increases the charges. As, token size for word "Shivank" in english is 2 only but if we do it in hindi the token-size will increases due to the minute spellings.
